# SmartVitals

SmartVitals is a React Native smartwatch health-monitoring application designed to provide users with a simple and intuitive dashboard for viewing important health and activity metrics.

## Features

* 📊 Health dashboard
* 👣 Step count tracking
* ❤️ Heart rate monitoring
* 🫁 SpO₂ (blood oxygen) monitoring
* ⌚ Designed for smartwatch-based health tracking
* 📱 Built with React Native

## Dashboard

The SmartVitals dashboard provides users with an overview of their daily health and activity data, including:

| Metric     | Description                                       |
| ---------- | ------------------------------------------------- |
| Steps      | Displays the user's step count and activity level |
| Heart Rate | Displays heart rate information                   |
| SpO₂       | Displays blood oxygen saturation information      |

## Getting Started

### Prerequisites

Make sure you have the required React Native development environment installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/sankalpostwal007/SmartVitals.git
```

Navigate to the project directory:

```bash
cd SmartVitals
```

Install dependencies:

```bash
npm install
```

Run the application using the appropriate React Native command for your development environment.

## Purpose

SmartVitals was developed as a project to explore mobile and wearable application development using React Native, with a focus on presenting health and activity data in a clear dashboard interface.
